Import a portal report

Excel or CSV from Flipkart Seller Hub or the Meesho Supplier Panel. Rows match parcels by AWB / Tracking ID, or by Order ID / Order Item ID / Sub Order No once an orders report has linked them. Only the columns in the file are filled; nothing is wiped.

Which report, in which order

  1. Flipkart: orders, status, sale price and SKU come in by themselves every hour through the Flipkart API. Import only the Settlement report (Payments → Settlements → download) to fill the money received.
  2. Meesho orders: Orders → download the order report with AWB and Sub Order No. This links each scanned AWB to its order.
  3. Meesho returns: Returns → download, to mark RTO and customer returns.
  4. Meesho payments: Payments → download the payment file; matched by Sub Order No.

Recognised columns include AWB, Tracking ID, Order ID, Order Item ID, Sub Order No, SKU, Status, Invoice Amount, Bank Settlement Value, Final Settlement Amount, Payment Date, UTR, Total Marketplace Fee.

Settlement per packet

What Flipkart or Meesho should pay you for one packet of each SKU after fees. The ledger uses it to work out the expected settlement when the portal hasn't filled it, and flags short payments. Rates are saved in the Sheet's Rates tab.
